# BMP581 絶対高度算出機能 実装計画

BMP581の気圧値から絶対高度を算出する機能および、周辺気象観測点からの海面気圧のIDW(逆距離加重法)補間を実装します。現行のBMP5センサー処理(ODR 10Hz, OSR設定, IIR設定, I2C 100kHz)や温度選択ロジック、ヒステリシスは維持します。

## Open Questions
* **気象データ更新頻度:** 現状 `WeatherService` は20分間隔で取得していますが、要件定義に合わせて「15分間隔」へ変更してよいでしょうか。
* **保存メタデータ:** `FRAM` 内の `FramSuperblock` の空き領域にBMP581の校正メタデータ（オフセット値、校正時刻、温度、補間海面気圧など、約24バイト）を追加する方針で進めます。現状の `ADDR_STATE` (0x0100) までは十分な空き(約200バイト)があるため問題ない想定ですが、よろしいでしょうか。

## Proposed Changes

### Storage Layer (設定保存層)
`FramSuperblock` 構造体にBMP581校正データの保存用フィールドを追加し、永続化します。

#### [MODIFY] `storage_records.h`
- `FramSuperblock` 構造体にBMP581の校正済みフラグ、オフセット値 (`pressureOffsetHpa`)、およびメタデータ(校正時刻、校正時の温度、校正時海面気圧など)を追加します。
- 環境データ記録 (`EnvironmentalRecord`) などの構造は極力維持しますが、高度の扱い（生高度かヒステリシス後か）を明確にします。

#### [MODIFY] `storage_manager.h` / `storage_manager.cpp`
- `getBmp581Calibration()` および `setBmp581Calibration()` のようなメソッドを追加し、FRAMのSuperblockを読み書きできるようにします。

---

### Weather Service (気象データ取得・保持層)
AMeDAS APIから近隣の複数観測点の海面更正気圧(`normalPressure`)を取得し、逆距離加重法(IDW)を用いてセンサー設置地点の海面気圧を空間補間します。

#### [MODIFY] `weather_service.h` / `weather_service.cpp`
- `fetchNearestStation()` を改修し、指定座標から近い上位 N 地点 (例: 5地点) を探索しキャッシュするようにします。
- `fetchSeaLevelPressure()` 内で、上記 N 地点の `normalPressure` を取得します。
- 距離の逆数二乗 ($1/d^2$) を重みとして IDW 補間計算を実装します。
- 有効な地点数が3地点以上の場合は `VALID`、それ未満の場合は `LAST_KNOWN` などの品質状態フラグを判定します。
- 補間結果と品質状態を `SensorManager` を経由して BMP5 センサーへ渡します。
- 定期更新のインターバルを20分から15分(900,000ms)へ変更します。

---

### Sensor Layer (センサー層)
BMP5基底クラスにて絶対高度計算パイプラインと個体オフセット校正(13.6m基準)を実装します。

#### [MODIFY] `bmp5_sensor_base.h`
- 補間海面気圧、品質状態、個体オフセット、校正メタデータを保持するメンバ変数を追加します。
- 生の絶対高度 (`rawAbsoluteAltitudeM_`) とヒステリシス後の表示高度 (`displayAltitudeM_`) を分離します。
- 校正処理を開始・実行するためのステートマシンまたは関数(例: `startCalibration()`, `updateCalibration()`)を追加します。

#### [MODIFY] `bmp5_sensor_base.cpp`
- **高度計算パイプライン変更**: 未補正気圧から保存済み個体オフセットを減算し、補間海面気圧と選択温度を用いて現行式で絶対高度を計算します。
- **ヒステリシス処理**: 計算成功後にのみ±0.5mのヒステリシスを適用し、表示高度を確定させます。
- **校正手順の実装**: 
  - 基準高度 13.6m に基づく期待気圧の逆算式を実装します。
  - 5分間 (10Hz = 3000点) のデータを収集し、残差の中央値 (またはトリム平均) をオフセットとして算出する校正フローを実装します。
  - 算出後の再計算で受入条件を満たせば `StorageManager` 経由で保存します。
- ログ出力にて、生高度、表示高度、使用された温度ソースや気圧場品質を明確に出力するよう変更します。

#### [MODIFY] `sensor_manager.h` / `sensor_manager.cpp`
- `WeatherService` からの補間海面気圧と品質状態を受け取るインターフェースを追加し、BMP581へ中継します。
- 外部APIまたはCLIからBMP581の校正トリガーを呼び出せるようラッパー関数を追加します。

## Verification Plan

### Automated Tests
- 新たに追加する逆距離加重法(IDW)や現行式の逆関数の計算精度（0.01m以内の一致）を検証するための単体テスト(可能であればNative環境でのテストコード)を作成、またはシミュレーションコードで計算結果の整合性を検証します。

### Manual Verification
1. **通常動作の確認**: オフセット0 hPa、固定の海面気圧を設定した場合に、現行の高度計算結果と一致することを確認します。
2. **校正の確認**: 実機(または模擬入力)にて 13.6m の校正をトリガーし、5分後に正しくオフセット値が計算・FRAMに永続化され、再起動後も適用されることを確認します。
3. **気圧場補間の確認**: AMeDASからのデータ取得時に、複数地点からのIDW補間結果が妥当であること、また取得失敗時や地点不足時に状態がフォールバックされることをログから確認します。
4. **ヒステリシスの確認**: 実際の気圧変動(または模擬変動)に対し、表示高度が±0.5mのデッドバンドに従って更新されることを確認します。
