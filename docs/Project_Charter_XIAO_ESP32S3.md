# Project Charter

## XIAO ESP32S3 センサプラットフォーム

Version: 1.0

## プロジェクトの目的

本プロジェクトは、ESP32-S3を中心とした再利用可能なセンサプラットフォームを構築することを目的とする。

目標は「動くサンプルコード」ではなく、「長期間拡張できる計測基盤」を作ることである。

------------------------------------------------------------------------

# 基本理念

1.  保守性を性能より優先する
2.  拡張性を短期的な実装速度より優先する
3.  障害が起きても可能な限り動作を継続する
4.  ハードウェア依存を局所化する
5.  小さく実装し、小さく検証する
6.  推測ではなくデータシートと実測を重視する

------------------------------------------------------------------------

# 設計原則

-   main.cpp は起動と更新のみ担当する
-   センサ同士は直接依存しない
-   ドライバはアプリケーションを知らない
-   ライブラリ固有APIはDriver層へ閉じ込める
-   共通処理はSensorManagerへ集約する
-   ISRではフラグ設定以外を行わない
-   delay()への依存を避ける
-   グローバル変数は最小限にする
-   エラーでも全体停止しない
-   変更は既存コードへの影響を最小化する

------------------------------------------------------------------------

# コーディングポリシー

-   可読性を最優先
-   小さなクラスを好む
-   一つのクラスは一つの責務
-   マジックナンバー禁止
-   constexprを優先
-   コメントは「何を」ではなく「なぜ」を書く

------------------------------------------------------------------------

# 品質基準

実装完了とは以下を満たすこと。

-   PlatformIOビルド成功
-   Upload成功
-   新しいWarningを増やさない
-   README更新
-   動作確認済み
-   エラー処理確認済み

------------------------------------------------------------------------

# Antigravityへの指針

実装時は以下を守る。

-   一度に一機能だけ追加する
-   各段階でビルドする
-   APIを推測で決めない
-   既存アーキテクチャを壊さない
-   疑問点はTODOとして残す
-   センサ追加でmain.cppを書き換えない構造を維持する

------------------------------------------------------------------------

# 将来像

本プラットフォームは以下へ発展できることを目標とする。

-   BLE
-   Wi-Fi
-   MQTT
-   LVGL
-   FreeRTOS
-   SDカード
-   OTA
-   nRF54L15との独自2.4GHz通信
-   複数センサノード管理
-   データロガー
-   リアルタイム可視化

------------------------------------------------------------------------

# 判断基準

設計で迷った場合は、次の順で優先する。

1.  保守性
2.  拡張性
3.  可読性
4.  信頼性
5.  性能
6.  コード量

------------------------------------------------------------------------

# 完成形

このプロジェクトの理想形は、

「新しいセンサを1個追加しても、既存コードをほとんど変更せず統合できること」

である。
