# T05 SCD41安定化・保守操作 実装記録

実施日: 2026-09-05

## 実装した内容

- CO₂の停止・通信失敗後は前値を無効化し、復旧後も連続3回の正常測定が揃うまで`Stabilizing`として隔離する。
- 復旧回数を最初のstop/startから、再発時の`reinit`＋ASC／温度offset再設定へ段階的に昇格した。再試行間隔は30秒、120秒、以後300秒とし、正常状態が5分継続するまで段階をリセットしない。
- 現地気圧のSCD41 commandは整数hPaが変化した時または60秒keepalive時だけ送信する。入力時刻と実command時刻を分離し、FRC直前には15秒以内の最新現地気圧を再送する。
- FRCはReady／Healthy、有効で15秒以内のCO₂、測定開始後3分以上、400～5000 ppmの外部基準、15秒以内の現地気圧を必須とした。
- FRCのcommand順を「気圧再適用 → stop → 500 ms待機 → FRC → restart」に固定した。FRC commandを試行した後はFRC自体が失敗しても必ずrestartを試す。
- FRC補正値は`raw - 0x8000`を32 bit符号付き演算してから`int16_t`へ格納し、負補正と`0xFFFF`拒否を正しく扱う。
- FRC／Factory Reset中はmaintenanceフラグで通常updateと気圧commandを排他する。
- Factory Reset APIは`RESET_SCD41`の完全一致tokenを必須化した。reset前後の全command戻り値、ASC=1、温度offset=2.0℃のread-back、測定再開を確認し、途中失敗を成功扱いしない。
- 通常起動時もASC／温度offsetの設定とread-backを厳格化し、どれか一つでも失敗または不一致なら測定開始前に初期化失敗とする。
- FRC／Factory Resetの成功・失敗と、復旧隔離状態をFRAM event journalへ保存する。FRC失敗時も要求基準値・直前CO₂・気圧・気圧age・測定継続時間をAPIへ返す。
- FRC APIは入力不正をHTTP 400、実行条件未成立を409、I²C lock不可を503、sensor command失敗を500へ分類した。JSON bodyは分割受信を処理できる専用handlerへ変更した。

## 残るGate

- 実機でSCD41のSDA／SCL通信障害、data-ready error、stop／FRC／restart各command失敗を注入し、HTTP応答、event、I²C内訳、CO₂無効化が一致することを確認する。
- 復旧後は3回連続正常sampleまでCSVのCO₂が空欄で、`Stabilizing`から`Healthy`へ一度だけ遷移することを確認する。
- 安定環境で48時間運転し、従来の26～41秒周期の復旧stormが再発しないこと、意図しないFRC／Factory Resetがないことを確認する。
- 外部基準器を使ったFRCを1回実施し、気圧age、signed補正値、再開後5 sampleのevent／CSVを照合する。

上記の物理障害注入と48時間連続試験を終えるまでは、T05を監査closeとは扱わない。
