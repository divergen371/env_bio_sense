# T02 UTC・PPS・TimeSource整合性 実装記録

## 対象

- P0-04 NTP秒／ミリ秒混同
- P1-01 GNSS UTC変換とHoldover未反映
- P1-02 記録時刻とPPS age

## 実装した契約

1. NTP境界は`reportNtpSyncSeconds`と命名し、POSIXのepoch秒をoverflow確認後に一度だけマイクロ秒へ変換する。
2. LC76Gの日付・時刻は`mktime`を使わず、タイムゾーン非依存のGregorian UTC変換を使う。
3. GNSS同期喪失時はClockのUTC anchorを維持したままsourceを`Holdover`へ変え、`disciplined=false`とする。
4. Clockはmonotonic、UTC、valid、source、disciplined、PPS ageを一つの`TimeSnapshot`として取得する。
5. CSVレコード時刻は最新GNSS fixの時刻をコピーせず、`appendRecord`時点のClock snapshotを使う。
6. `PPS_AgeMs`は直近PPS monotonic時刻から毎回算出し、未観測・逆転・32 bit範囲超過は`UINT32_MAX`とする。

## 残る実機Gate

- GNSS同期後にPPS／NMEAを遮断し、CSVが`TimeSource=HOLDOVER`、`GNSS_TimeDisciplined=0`、増加する`PPS_AgeMs`を示すこと。
- GNSSを受信できない状態でNTP fallbackを成立させ、1970年へ飛ばず現在UTCになること。
- Manual/NTP時にも`TimestampUtc`が記録時刻として単調に進み、GNSS fix ageとは独立すること。
- PPS再開後、3回連続整合を経てGNSSへ復帰すること。
